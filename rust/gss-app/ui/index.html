How to use this app

    
Search Scholar, screen the results, then export what you keep.

    

      

        
First run

        
    
          
  1. Type a query and press Enter. Pages defaults to 1; "Search options" has pages, year range, and relevance ranking.
    2. 
          
  2. Results appear with an Unknown PDF status. That is expected — nothing has been verified yet.
    3. 
          
  3. Optional: run Actions → Check metadata + PDFs to fill in DOI, journal ranks, citations, open-access status, and public-PDF availability. It contacts Crossref and OpenAlex, so it is slower than a search.
    4. 
          
  4. Screen papers with Include / Maybe / Exclude, then export.
    5. 
        

      


      

        
Screening papers

        
    
          
  • Click a row to open the inspector on the right: metadata, notes, tags, exclusion reason, and the abstract.
    • 
          
  • Use the row checkboxes (or Ctrl+click, or Shift+click for a range) to act on many rows at once.
    • 
          
  • Decisions are saved per DOI, or per title when there is no DOI, so they survive a new search or a restart.
    • 
          
  • Unsaved inspector edits are never thrown away silently — you are asked before switching papers.
    • 
        

      


      

        
What the columns mean

        
Only Title, Authors, and Link come from Google Scholar. Everything else is enrichment or your own screening.

        

          
Decision
Your screening verdict: undecided (blank), include, maybe, or exclude with a coded reason.

          
PDF
Whether this app found a downloadable public PDF. "Unknown" means not checked yet. Distinct from open access.

          
Index
Indexing services listing the journal (SJR, SINTA, SCOPUS, DOAJ), from the ranking file you imported.

          
Rank
SJR quartile / SINTA rank of the journal. Describes the journal, never the paper.

          
Cited
Citation count from Crossref or OpenAlex. A real 0 differs from blank (not checked).

          
OA
Open-access status from OpenAlex: gold, green, bronze, hybrid, closed. "Closed" means OpenAlex knows of no open version.

          
Tags
Your own labels for grouping papers by theme or method.

        

        
Hover or focus the ? beside a column header for the same explanation in place.

      


      

        
Exporting

        
    
          
  • Export opens one dialog: choose a format, then choose which papers — filtered rows, selected rows, or everything collected. The counts update as you change scope.
    • 
          
  • CSV and BibTeX/RIS keep the fixed column/key contract of the original Python implementation, so downstream scripts keep working.
    • 
          
  • Excel adds formatting, freeze panes, and grouped sheets; other formats cover JSON, Markdown, TSV, EndNote, CSL-JSON, and a reading list.
    • 
          
  • Exports are written together with a temporary file and then renamed, so an interrupted write cannot leave a half file.
    • 
        

      


      

        
Systematic review tools

        
    
          
  • PRISMA counts summarises identified / screened / included / excluded.
    • 
          
  • Screening log exports every decision with its reason, tags, note, and timestamp.
    • 
          
  • Near-duplicate report finds likely duplicate records above a similarity threshold.
    • 
          
  • Baselines snapshot a search so a later search can be diffed against it.
    • 
          
  • Add papers imports your own CSV/JSON export, or resolves pasted DOIs through Crossref.
    • 
        

      


      

        
Keyboard

        

          
Enter in the query box
Start a search.

          
Arrow keys in the table
Move between rows; Home/End jump to the ends.

          
Space
Toggle selection on the focused row.

          
Shift+Arrow
Extend the selection.

          
Enter on a row
Open the inspector.

          
Ctrl+A
Select every visible row.

          
Ctrl+Shift+A
Clear the selection.

          
Ctrl+E
Open the export dialog on BibTeX.

          
Esc
Close a popover, then the inspector, then cancel a running operation.

        

      


      

        
Limits and honesty

        
    
          
  • Google Scholar rate-limits and blocks automated access. When that happens the app says so and keeps what it already collected; it does not bypass CAPTCHAs or rotate proxies.
    • 
          
  • Enrichment data is only as good as Crossref/OpenAlex coverage. A blank value means unknown, not zero.
    • 
          
  • Ranking labels describe journals, not the quality of an individual paper.
